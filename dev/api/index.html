API reference

SeismicWavePC — Module
SeismicWavePC

Julia version of the OpenSWPC finite-difference seismic wave propagation code (Maeda et al., 2017), for 2D (P-SV, SH) and 3D visco-elastic media given as GeophysicalModelGenerator CartData, or built per MPI process (DistributedModel). Runs on CPUs and GPUs (KernelAbstractions) and on multiple MPI processes (ImplicitGlobalGrid).

source

Simulation

SeismicWavePC.simulate — Function
result = simulate(model; dt, nt, sources, kwargs...)

Run a visco-elastic wave propagation simulation (OpenSWPC algorithm) on the velocity model model and return Seismograms.

model is a CartData (coordinates in km, z up; constant spacing in x and y, constant or smoothly varying in z) with fields rho [kg/m³], vp, vs [km/s] and optionally Qp, Qs (default: no attenuation) and the Thomsen parameters epsilon, delta, gamma (VTI anisotropy; vp, vs are then vertical velocities). Cells with vp = vs = 0 are air: the free surface and topography follow from that. Cells with vs = 0 and vp > 0 are water. A CartData of size (nx, 1, nz) gives a 2D simulation in the x-z plane. A model too large to hold as a whole is given as a DistributedModel, of which every MPI process builds only its own subdomain.

Keyword arguments

  • dt, nt: time step [s] and number of steps; tbeg = 0.0 is the start time.
  • sources: MomentTensorSource, ForceSource, PlaneWave or a vector of them (see DoubleCoupleSource); stf = :kupper source time function: a name or any function (see moment_rate, SampledSTF).
  • stations = Station[]; seismograms (velocity, displacement, stress, strain) are recorded every record_every = 1 steps.
  • interpolation = :cell: sources and stations at the cell that contains them (as OpenSWPC), or :sinc at their exact position, between grid points (Kaiser-windowed sinc interpolation, Hicks 2002; strain is then still taken at the cell).
  • wave = :psv: :psv or :sh, for 2D models.
  • grid = :auto: a deformed 2D model (a terrain-following mesh, see curvilinear_mesh) runs on a curvilinear grid (SeismicWavePC.simulate_curvilinear: SBP finite differences, the free surface at the true topography), any other on the staggered grid; :curvilinear or :staggered to choose.
  • free_surface = :openswpc: the shear modulus at the shear-stress points is the harmonic mean of the four cells around them, zero next to air or water (as OpenSWPC). On a stair-stepped topography this also zeroes the shear stress at the inner corners of the steps, so a top cell one cell wide in x (or y) has no shear coupling to the ground in that direction and its horizontal velocity stays exactly zero there. :corners takes the harmonic mean of the three solid cells at these inner corners (one cell of the four with μ = 0); flat surfaces and outer corners are unchanged (identical results on a flat free surface). P-SV and 3D (SH has no such points).
  • absorber = :pml: absorbing boundary at the sides and the bottom, :pml (perfectly matched layer), :mpml (multiaxial PML) or :cerjan (sponge); na = 20 is its thickness in cells. The PML can grow exponentially where a soft surface layer (high Poisson ratio, e.g. water-saturated sediments) reaches into the side layers. The M-PML is stable there: each layer also damps the derivatives parallel to it, with the fraction mpml_ratio = 0.1 of the layer's damping. It reflects more than the PML (less than :cerjan), mostly as a slowly decaying long-period residual. (:pml damps the top h of the side layers in z too: h = na cells, or on a stretched z axis the thickness of the bottom layer; with less air than h this reaches into the ground. :mpml does not damp at the free surface.) Plane waves need :pml.
  • fq_min = 0.05, fq_max = 5.0, fq_ref = 1.0: frequency band [Hz] of constant Q, and reference frequency of the velocities.
  • density_unit = :kg_m3: unit of rho, or :g_cm3 (as in OpenSWPC).
  • snapshot_every = 0: if > 0, write the velocity field every so many steps to ParaView files in snapshot_dir = "snapshots".
  • snapshots = nothing: Snapshots of planes as netCDF files (OpenSWPC format; needs using NCDatasets), written every snapshot_every steps into snapshot_dir instead of the ParaView files.
  • callback = nothing: a function callback(wavefield::CartData, t) that is called every snapshot_every steps (on rank 0) instead of writing ParaView files, e.g. to plot the wavefield while the simulation runs. wavefield has the field V [m/s].
  • checkpoint = nothing: file name (without extension) for checkpoints, written every checkpoint_every steps (one file per MPI rank); with restart = true the simulation continues from the last checkpoint. Snapshots before it are not rewritten.
  • backend = CPU(): KernelAbstractions backend, e.g. CUDABackend(), ROCBackend(), MetalBackend().
  • T = Float32: floating point type of the wavefield.
  • nproc = 1: MPI processes in x (2D), or (npx, npy) (3D); start julia with mpiexec -n npx*npy.
  • wavefield = true: return the velocity field at the end (collected on rank 0) in the result; false by default for a DistributedModel.
  • verbose = true: print a summary and the progress (on rank 0).
  • derivatives = false: also the divergence and curl of the velocity at the stations (div, curl of the result), from 4th-order centred differences over dh [km] (default: the grid spacing in x) between auxiliary stations around each station; at stations on the surface the vertical derivatives are one-sided from below.

SeismicWavePC.Seismograms — Type
Seismograms

Result of simulate. Fields:

  • t: times [s] of the samples
  • v: velocities v[it, component, station] [m/s], components along components (z positive up)
  • u: displacements [m], like v
  • stress [Pa] and strain: stress[it, component, station], components along tensor_components
  • stations: the Stations
  • components: (:x, :z) (P-SV), (:y,) (SH) or (:x, :y, :z) (3D)
  • tensor_components: (:xx, :zz, :xz) (P-SV), (:yz, :xy) (SH) or (:xx, :yy, :zz, :yz, :xz, :xy) (3D)
  • wavefield: velocity field V [m/s] at the end of the simulation as CartData (on MPI rank 0; nothing elsewhere)
  • div, curl: with simulate(...; derivatives = true), the divergence div[it, station] and the curl curl[it, component, station] (components x, y, z) of the velocity [1/s]; otherwise nothing

r["name"] returns the (nt, ncomponents) matrix of the station called "name".

SeismicWavePC.Station — Type
Station(name, x, y, z; surface=false)
Station(name, lon, lat, z, proj::ProjectionPoint; surface=false)

Receiver at model coordinates x, y, z [km] (z up, as in the CartData), or at a geographic location that is projected with the same ProjectionPoint that was used to create the model (see GeophysicalModelGenerator.convert2CartData). SeismicWavePC.MomentTensorSource — Type
MomentTensorSource(x, y, z, M0, M; t0=0.0, trise=1.0, stf=nothing)

Point source at model coordinates x, y, z [km] (the CartData frame: x east, y north, z up). M0 is the scalar moment [N m] (per unit length [N m/m] in 2D) and M = (xx, yy, zz, yz, xz, xy) the moment tensor in the same frame, normalized so that M0 sets the size. t0 is the rupture start time and trise the rise time [s]. stf: the source time function of this source (as the stf keyword of simulate, e.g. a SampledSTF); nothing: the one of the simulation.

SeismicWavePC.finite_fault — Function
finite_fault(; top, strike, dip, length, width, nl, nw, slip, rake, mu=nothing, model=nothing, density_unit=:kg_m3,
             hypocenter=(0.0, width / 2), vr=nothing, t0=nothing, trise=1.0, stf=nothing, dims=3)

A planar finite fault as nl × nw subfaults (along strike × down dip), each a DoubleCoupleSource at its centre with the scalar moment μ A slip. Returns a vector of MomentTensorSources for the sources of simulate and misfit_gradient.

  • top = (x, y, z) [km]: the centre of the upper edge (model coordinates, z up); strike, dip [°] as for DoubleCoupleSource (strike clockwise from north = +y, the fault dips to the right of the strike direction); length, width [km] along strike and down dip.
  • slip [m], rake [°], trise [s]: numbers, functions f(a, b) of the position on the fault (a [km] along strike from the centre, b [km] down dip from the top edge), or nl × nw matrices.
  • mu [Pa]: a number or a function mu(x, y, z); or model: the shear modulus ρ vs² at the node nearest to each subfault (also of curvilinear meshes).
  • Rupture times: from the hypocenter = (a, b) on the fault and the rupture velocity vr [km/s] (t0 [s] the start there), or t0 alone as a number, function f(a, b) or matrix.
  • stf: the source time function of the subfaults (default: the stf of the simulation), e.g. a SampledSTF, or a function f(a, b) returning one per subfault.
  • dims = 2 (or a 2D model): a fault in the x–z plane of a 2D model, striking along y (strike 0 or 180); nl = 1, and the moments are per unit length [N m/m].

SeismicWavePC.read_sources — Function
read_sources(file; format, proj=nothing, model=nothing, mu=nothing, density_unit=:kg_m3)

The sources of an OpenSWPC source list file (fn_stf), one per line (# comments and blank lines are skipped): a vector of MomentTensorSources, or of ForceSources for the body-force formats. format is OpenSWPC's stf_format:

  • "xym0ij", "xym0dc", "xymwij", "xymwdc", "xydsdc": x, y [km] (OpenSWPC's x north, y east), depth [km], start time, rise time [s], then the scalar moment M0 [N m] or the magnitude Mw, or slip D [m] and area S [m²], and the moment tensor (xx, yy, zz, yz, xz, xy in OpenSWPC's frame) or strike, dip, rake [°];
  • "llm0ij", "llm0dc", "llmwij", "llmwdc", "lldsdc": the same at longitude, latitude (needs proj, the ProjectionPoint of the model);
  • "psmeca": longitude, latitude, depth, the moment tensor in spherical coordinates (rr, tt, ff, rt, rf, tf) and the exponent of the moment in dyn cm (GMT psmeca -Sm, Global CMT); start time 0, the rise time from the moment as OpenSWPC;
  • "xy", "ll" (body forces): x, y or longitude, latitude, depth, start time, rise time, fx, fy, fz [N] (OpenSWPC's frame: north, east, down).

Positions and components are converted to the frame of the model (x east, y north, z up). The slip formats ("..dsdc") need the shear modulus: mu [Pa] (a number or a function mu(x, y, z)) or the model (ρ vs² at the nearest node). OpenSWPC's horizontal rotation phi is not applied, and the 3-parameter asymcos time function is not supported.

SeismicWavePC.read_srf — Function
read_srf(file; proj, mu=nothing, model=nothing, density_unit=:kg_m3)

The point sources of a kinematic rupture in the Standard Rupture Format (SRF, versions 1 and 2; Graves, SCEC Broadband Platform): one MomentTensorSource per point (a double couple with strike, dip, rake), at its longitude, latitude and depth (projected with proj, the ProjectionPoint of the model), starting at the rupture time TINIT, with its slip-velocity function as SampledSTF and the moment μ × area × slip. Slip in the second in-plane direction (rake + 90°) is a second source with its own slip-velocity function; fault opening (u3) is not supported. μ: from the S velocity and density of each point (version 2), else mu [Pa] (number or function mu(x, y, z)) or the model.

SeismicWavePC.read_cmtsolution — Function
read_cmtsolution(file; proj)

The point sources of a CMTSOLUTION file (SPECFEM, Global CMT; several blocks for a finite source): moment tensors (Mrr, Mtt, Mpp, Mrt, Mrp, Mtp in dyn cm) at their latitude, longitude and depth (projected with proj), with SPECFEM's source time function: a Gaussian moment rate of the given half duration, centred at the time shift (t0).

SeismicWavePC.PlaneWave — Type
PlaneWave(wave; depth, length, strike=0.0, dip=0.0, rake=0.0)

Plane P (wave = :p) or S (wave = :s) wave, as in OpenSWPC (pw_mode); use it in sources. At the start time the pulse lies between depth and depth + length [km] (measured along its direction of propagation) and travels upwards, inclined by dip [°] from the vertical, towards the azimuth strike + 180° [° clockwise from north]. rake [°] sets the polarization of an S wave. The shape is the source time function stf of the simulation (with a "rise time" of length), and the velocity amplitude is of the order of 1/length (in m/s, the OpenSWPC convention).

In 2D the wave travels in the x-z plane (OpenSWPC fixes strike = 90°, and rake = 90° (P-SV) or 0° (SH, S waves only)). Use the PML absorber (the default): its side boundaries let the plane wave pass.

source
SeismicWavePC.TeleseismicWave — Type
TeleseismicWave(wave; angle, box, backazimuth=270.0, t0=0.0, trise, amplitude=1e-6)

A plane :p, :sv or :sh wave from below, injected along the sides and the bottom of box (total-field / scattered-field method): inside the box the simulation gives the total field (the wave, its reflections at the free surface and at layer interfaces, and the waves scattered by the structure in the box), outside only the scattered waves, which the absorbing boundaries take out. Use it in sources, also for misfit_gradient (the gradient is exact inside the box).

  • angle [°]: angle of incidence in the half-space below the model (from the vertical);
  • box: (xmin, xmax, zmin) in 2D, (xmin, xmax, ymin, ymax, zmin) in 3D [km]; the box reaches up to the free surface;
  • backazimuth [° clockwise from north (y)]: direction towards the source; the wave travels the opposite way (default 270°: from the west, towards +x; in 2D only 90° and 270° make sense);
  • t0 [s]: time at which the wave reaches the box first (its deepest corner on the source side);
  • trise [s] and the source time function stf of the simulation: the particle velocity of the incoming wave is amplitude * stf(t); for source time functions with integral 1 (the default :kupper, :gaussian) the wave carries the displacement amplitude [m].

The model must be horizontally layered (elastic, no water) along the box boundary and below: that is the background in which the wave is computed exactly. The box must keep 4 cells from the absorbing layers. On curvilinear grids the box is made of the nodes inside it (and the mesh row nearest to its bottom); the topography must be flat along its sides, and its bottom 5 nodes away from block interfaces.

SeismicWavePC.moment_rate — Function
moment_rate(stf, t, t0, tr)

Normalized moment-rate function (source time function, integral 1) at time t of a source with origin time t0 and rise time tr. stf is

  • one of :kupper (default in OpenSWPC), :boxcar, :triangle, :herrmann, :cosine, :texp;
  • :ricker: a Ricker wavelet with the peak frequency 1/tr, centred at t0 + tr (integral 0, peak value 1/tr; common in benchmarks);
  • :gaussian: a Gaussian centred at t0 + tr with width tr (√π/tr · exp(-(π(t - t0 - tr)/tr)²), integral 1), and :gaussian_derivative: its time derivative times tr/π (integral 0);
  • :fuchs_mueller: the Fuchs-Müller wavelet of SOFI, sin(2πfτ) - sin(4πfτ)/2 for τ = t - t0 in [0, 1/f], f = 1/tr (integral 0; times 1/tr, as :ricker); :sin3 is :kupper (SOFI's sin³ wavelet);
  • BerlageSTF and KlauderSTF (SOFI's Berlage and Klauder wavelets, with their parameters);
  • :step: a unit step at t0 (e.g. a force switched on: a static load; for moment tensors the moment grows linearly);
  • :delta: a unit impulse at t0 (the moment steps from 0 to M0; a force gives a unit impulse), in simulations the time step that contains t0 (1/dt there);
  • any function stf(t, t0, tr), e.g. a SampledSTF of sampled values.

SeismicWavePC.SampledSTF — Type
SampledSTF(t, values)

Source time function (moment rate, or force history) given by values at the times t [s] after the origin time t0 of the source, linearly interpolated, zero outside t. For moment tensors and forces the integral should be 1 (M0 and the force set the size). Use it as simulate(...; stf=SampledSTF(t, values)); the gradient of the misfit with respect to it is source_gradients[n].stf of misfit_gradient.

source
SeismicWavePC.BerlageSTF — Type
BerlageSTF(; n=1.5, α, φ0=-90)

The Berlage wavelet (Aldridge, 1990; as in SOFI) as a source time function: τⁿ exp(-ατ) cos(2πfτ + φ0) for τ = t - t0 ≥ 0 with the centre frequency f = 1/trise and φ0 in degrees, scaled so that its envelope peaks at 1/trise. Use it as stf.

source
SeismicWavePC.KlauderSTF — Type
KlauderSTF(; fmin, fmax, tsweep, ntwidth=5)

The Klauder wavelet (the autocorrelation of a linear sweep from fmin to fmax [Hz] of duration tsweep [s]; as in SOFI): sin(πkτ(T - τ)) / (πkτ T) cos(2π fc τ), k = (fmax - fmin)/T, fc = (fmax + fmin)/2, centred ntwidth/fc after t0, zero beyond ntwidth centre periods on either side, with cosine tapers over the first and last 20 %; peak fc. trise is not used (give trise = 1/fmax for the absorbing layers). Use it as stf.

SeismicWavePC.Snapshots — Type
Snapshots(; xy=nothing, xz=nothing, yz=nothing, fs=false, ob=false, quantities=(:v,), decimate=1, title="swpc", pieces=false)

Snapshots of planes written as netCDF files in the format of OpenSWPC, every snapshot_every steps into snapshot_dir (pass to simulate as snapshots; needs using NCDatasets):

  • xy = z [km]: horizontal plane at height z; xz = y, yz = x [km]: vertical sections (in 2D: xz = true for the model)
  • fs = true: the free surface (first solid cell below the air), ob = true: the ocean bottom (3D)
  • quantities: :v (velocity Vx, Vy, Vz [m/s]), :u (displacement Ux, … [m]) and :ps (divergence div and rotation rot_x, rot_y, rot_z [1/s]; in 2D P-SV divergence and rotation)
  • decimate: every decimate-th cell per direction (an integer or a tuple)
  • pieces = true: every MPI process writes the points of its own subdomain to files of its own, named with its rank (swpc.3d.fs.v.0000.nc, …), instead of process 0 collecting every plane: then no process holds a whole plane. read_snapshots reads either kind.

Files are named <title>.<solver>.<plane>.<quantity>.nc (e.g. swpc.3d.fs.v.nc) with the coordinates x, y, z [km, z positive down as in OpenSWPC], time t and the medium rho, lambda, mu; velocity files of horizontal planes also get the peak values max-V (vertical), max-H (horizontal) and max-A (vector) over all time steps. Unlike OpenSWPC, the components are at the cell centres with x east, y north and z up, and t is the time of the snapshot.

On curvilinear grids the points are the nodes of the mesh columns: fs is the topography, xy planes and the sections are interpolated at regular heights (zero, and medium NaN, above the topography); the divergence and rotation (:ps) from the SBP operators at the nodes.

SeismicWavePC.read_snapshots — Function
s = read_snapshots(file)

Read the snapshots of one plane and quantity written by simulate (see Snapshots; needs using NCDatasets), e.g. read_snapshots("snapshots/swpc.3d.fs.v.nc"). If they were written in pieces (pieces = true: swpc.3d.fs.v.0000.nc, …), the pieces are put together, so that both kinds read the same; pieces that overlap or leave points out, or a single file next to pieces of it (files of another run), are an error. Returns a SnapshotSeries:

  • s.axes: the two coordinates of the plane as name => values [km]; s.t: the times [s]; s.variables: the names of the fields
  • s["Vx", k]: the field Vx of snapshot k as a matrix
  • s["max-H"]: a field without time (medium, peak values) as a matrix; for a field with time all snapshots, (n1, n2, nt)

SeismicWavePC.curvilinear_mesh — Function
mesh = curvilinear_mesh(x, surfaces; dz, bottom)

A deformed 2D CartData (size nx × 1 × nz, km) for simulate on a terrain-following grid: one grid line follows each of the surfaces, top first: the topography, then interfaces with a jump in the material (e.g. a Moho), each a function z(x) [km] or a surface CartData (nx × 1 × 1, linearly interpolated). The bottom is flat at bottom [km]; between two surfaces z is blended linearly. The columns are vertical, at the nodes of the SBP operator over first(x)…last(x) with length(x) points (equidistant except the outermost few); between two surfaces at least 13 nodes, with about dz [km] spacing where the layer is thickest.

Fill the fields rho [kg/m³], vp, vs [km/s] (and optionally Qp, Qs) at the nodes with the usual GMG tools, e.g. layers with Z .< moho.(X) and a magma chamber with add_ellipsoid!, then simulate(addfield(mesh, (; rho, vp, vs)); ...).

source
mesh = curvilinear_mesh(x, y, surfaces; dz, bottom)

The 3D version: columns at the SBP nodes in x and y, surfaces functions z(x, y) [km] or surface CartData (nx × ny × 1, bilinearly interpolated).

simulate_curvilinear(model; tmax or nt, sources, ...)

2D P-SV or SH (wave) on a deformed (terrain-following) CartData (see curvilinear_mesh); called by simulate for such a model. Keywords as in simulate, and: dt = nothing (from the spectral radius of the operator: 90 % of the leapfrog limit), tmax (duration) instead of nt, absorber = :impedance (or :pml: also a PML of na = 20 nodes at the sides and the bottom, :mpml: the multiaxial PML with mpml_ratio = 0.1, :cerjan: a sponge of na nodes, or :none: free sides and bottom), jump = 0.05 (relative jump of vp or vs that makes a grid row an interface, see find_blocks), nproc MPI processes along x (2D) or (npx, npy) (3D): start julia with mpiexec; the columns are not split.

SeismicWavePC.DistributedModel — Type
DistributedModel(f, x, y, z; attenuation=true, anisotropy=false)

A model that is built piece by piece, for runs on several MPI processes with models too large to hold as a whole: every process asks only for the part of the model in its own subdomain (see nproc of simulate).

x, y, z are the coordinates [km] of the cell centres of the whole grid (z up; constant spacing in x and y, constant or smoothly varying in z), as for a CartData made with xyz_grid(x, y, z); a single y gives a 2D model. f(ix, iy) returns the model of the columns x[ix], y[iy] (index ranges) over all of z: a CartData, or a NamedTuple of arrays of size (length(ix), length(iy), length(z)), with the fields rho, vp, vs and optionally Qp, Qs (as in a CartData model). It is called once per process, for a range that reaches a few cells into the neighbouring subdomains and leaves out the absorbing layers at the sides, whose medium continues the cells next to them.

attenuation = false leaves out the memory variables of the attenuation (for models without finite Qp, Qs). anisotropy = true makes the model VTI: f may then also return the Thomsen parameters epsilon, delta, gamma (0 if missing).

x, y, z = range(0, 100, 2001), range(0, 80, 1601), range(-30, 2, 641)
model = DistributedModel(x, y, z; attenuation=false) do ix, iy
    X, Y, Z = xyz_grid(x[ix], y[iy], z)
    air = Z .> 0
    (rho=ifelse.(air, 1.0, 2700.0), vp=ifelse.(air, 0.0, 5.0), vs=ifelse.(air, 0.0, 2.9))
end
result = simulate(model; nproc=(2, 2), dt, nt, sources, stations)

Sources are MomentTensorSources and ForceSources at their cells (interpolation = :cell); plane and teleseismic waves, interpolation = :sinc, misfit_gradient and born need a CartData. The wavefield at the end is not collected, unless simulate is called with wavefield = true.

DistributedModel(f, x, y, nz::Integer; attenuation=true, anisotropy=false)

The same for a curvilinear grid (see curvilinear_mesh): x, y are the nodes [km] of the columns (the SBP nodes, e.g. sbp_nodes(a, b, n) of GMG), nz the number of nodes in every column, and f(ix, iy) returns the deformed CartData of the columns x[ix], y[iy] (size (length(ix), length(iy), nz), e.g. made with GMG's curvilinear_grid and a fixed number of cells per layer) with the fields rho, vp, vs (optionally Qp, Qs, epsilon, delta, gamma), or a NamedTuple with these and the heights Z [km]. Every process asks for its columns and a few more.

SeismicWavePC.random_medium — Function
xi = random_medium(x, y, z; spectrum=:vonkarman, a, epsilon, kappa=0.5, seed=nothing)

Gradients and inversion

SeismicWavePC.misfit_gradient — Function
J, gradient, source_gradients = misfit_gradient(model, observed::Seismograms; sources, misfit=L2Misfit(), kwargs...)
J, gradient, source_gradients = misfit_gradient(model, observed::Vector{Seismograms}; sources::Vector, kwargs...)

Misfit J between the velocity seismograms of a simulation and observed (whose stations are used), and its gradient with respect to the model and the sources. With a vector of observed seismograms and a vector of sources (one entry per shot: a source or a vector of sources) the misfits and model gradients of all shots are summed.

  • misfit: L2Misfit (default: J = ½ Σ (v - v_observed)², optionally with weights, time windows, an inverse covariance matrix and normalization per trace), TravelTimeMisfit (cross-correlation time shifts), EnvelopeMisfit, PhaseMisfit (instantaneous phase), TFPhaseMisfit (time-frequency phase), any of them on band-pass filtered seismograms with Filtered, or any function (syn, obs, t) -> (J, ∂J/∂syn) of the synthetic and observed velocities [it, component, station] [m/s] and the sample times t [s]. With several shots: one misfit for all, or a vector with one per shot (event weights, e.g. from geographic_weights).
  • mute = (sources=r, stations=r): taper the model gradient to 0 at the sources and stations within the distance r [km] (the gradient is large and of little use next to them).
  • illumination = true: also return the illumination of the model by the sources, Σₜ |v|² of the forward wavefield [(m/s)²] per cell, as the field illumination of gradient (summed over shots). Dividing the gradient by it is a simple preconditioner (diagonal pseudo-Hessian) for inversions, and gives illumination-compensated images in reverse-time migration (see the Marmousi2 RTM example).
  • kwargs are those of simulate (dt, nt, stf, record_every, absorber, T, backend, nproc, …) and must describe the simulation that observed is compared with.
  • gradient: a CartData on the grid of model with the fields rho, vp, vs, Qp, Qs (VTI models: also epsilon, delta, gamma): ∂J/∂ of the model field in its units (per kg/m³ (or g/cm³ with density_unit = :g_cm3), per km/s, per unit Q). Cells in the absorbing layers are homogenized in the simulation, so their sensitivity is added to the cells next to the layers.
  • source_gradients: one entry per source (per shot: a vector of them), nothing for plane waves and ignored sources:
    • moment tensors: M (∂J/∂ of the six components M0 .* M [per N m]), M0 (at fixed M);
    • forces: F (∂J/∂ of fx, fy, fz [per N]);
    • both: x, y, z (location [per km]; exact with interpolation = :sinc, otherwise from the spatial derivative of the adjoint field, as the source is injected at a single cell), t0, trise [per s], and stf: ∂J/∂ of the moment rate (source time function) at the times t.

method

  • :adjoint (default): adjoint-state method with adjoint kernels (transposed stencils, including the free-surface cells and the PML with adjoint PML memory variables, and adjoint memory variables of attenuation), on all backends (CPU threads, GPUs); about 5 forward simulations. It is the exact gradient of the discrete simulation (to rounding errors), except for the Cerjan sponge, the side extrapolation of plane waves and the density in the source cell of P-SV forces.
  • :ad: reverse-mode automatic differentiation of the whole simulation (needs using Enzyme): exact in all cases, but ~20-50 forward simulations, CPU and one process only, the default misfit only and no source gradients. Use T = Float64 with it.

The wavefields are saved every checkpoint_steps steps (default: balances the memory of the checkpoints, kept in host memory, and of the velocity fields of the steps in between, kept on the device), and the steps in between are recomputed in the reverse pass. With nproc (MPI, as in simulate) every process gets all results. Plane waves enter as a fixed initial wavefield (their dependence on the medium is not differentiated).

source
SeismicWavePC.born — Function
background, scattered = born(model, δm; sources, stations, T=Float32, kwargs...)

Born (linearized) modelling: the seismograms scattered of the model perturbation δm to first order, J δm (J: the Jacobian of the seismograms with respect to the model), and the seismograms background of model, from one simulation.

  • δm: a CartData on the grid of model with any of the fields rho, vp, vs, Qp, Qs (and, for VTI models, epsilon, delta, gamma; missing fields: no perturbation), in the units of the model.
  • kwargs are those of simulate (dt, nt, stf, wave, interpolation, absorber, backend, …); T is the floating-point type (Float64 for tests of the linearization).

It is the exact derivative of the discrete simulation, the transpose of the gradient of misfit_gradient: for the L2 misfit, misfit_gradient gives Jᵀ r for the residuals r, and ⟨J δm, r⟩ = ⟨δm, Jᵀ r⟩. Together they give Gauss-Newton Hessian-vector products JᵀJ δm, and least-squares migration. It costs about 2.5 forward simulations on GPUs and 4.5 on CPU threads, on one or several MPI processes (nproc), on the staggered and on curvilinear grids. Not (yet) for teleseismic waves (plane waves are not differentiated, as in misfit_gradient).

SeismicWavePC.L2Misfit — Type
L2Misfit(; weights=1, window=nothing, invcov=nothing, normalize=false)

Least-squares misfit J = ½ Σ w (v - v_observed)² of the samples in the time window.

  • weights: a number, one per station (vector), per component and station (matrix nc × nstations) or per sample (array like the seismograms).
  • window: nothing (all samples), (t1, t2) [s] for all stations, or a vector of (t1, t2), one per station.
  • invcov: an inverse covariance matrix of the samples of a trace (nt × nt, symmetric), for correlated noise: J = ½ Σ_traces w rᵀ invcov r with the residuals r in the window (weights per trace then).
  • normalize = true: divide the misfit of each trace by the energy Σ v_observed² of the observed trace in the window (traces without signal are skipped), so that distant and near stations count alike.

SeismicWavePC.TravelTimeMisfit — Type
TravelTimeMisfit(; weights=1, window=nothing)

Cross-correlation travel-time misfit J = ½ Σ w τ² over the traces (station and component), with τ the time shift [s] of the synthetic against the observed trace (positive: synthetic late) at the maximum of their cross-correlation in the time window, refined to a fraction of a sample by a parabola. weights: a number, one per station or per component and station (nc × nstations); window as for L2Misfit. Traces without signal are skipped.

SeismicWavePC.EnvelopeMisfit — Type
EnvelopeMisfit(; weights=1, window=nothing)

Envelope misfit J = ½ Σ w (E - E_observed)² (Bozdağ et al., 2011) with the envelopes E = √(v² + H[v]²) (H: Hilbert transform) of the traces in the time window. Insensitive to the phase: robust against cycle skipping (surface waves, poor starting models), but with little resolution; often used first, followed by PhaseMisfit or L2Misfit. weights per trace (number, per station, or nc × nstations), window as for L2Misfit.

source
SeismicWavePC.PhaseMisfit — Type
PhaseMisfit(; weights=1, window=nothing, waterlevel=0.05)

Instantaneous-phase misfit (Bozdağ et al., 2011) in the exponentiated form of Yuan et al. (2020), free of phase wrapping: J = ½ Σ w [(v/E - v_obs/E_obs)² + (H[v]/E - H[v_obs]/E_obs)²], the squared difference of exp(iφ) of the analytic signals, with the envelopes E = √(v² + H[v]² + ε²) and ε = waterlevel · max E_observed of the trace. Independent of amplitudes (source strength, attenuation, site effects). weights and window as for EnvelopeMisfit.

source
SeismicWavePC.TFPhaseMisfit — Type
TFPhaseMisfit(; width, band=nothing, weights=1, window=nothing, waterlevel=0.01)

Time-frequency phase misfit (Fichtner et al., 2008): J = ½ Σ w Σ_τ,f W² Δφ(τ, f)² with the phase difference Δφ = arg(S Õ*) of the Gabor transforms S, Õ of the synthetic and observed trace (Gaussian windows exp(-(t-τ)²/2width²) [s] every width/2), weighted by W = |Õ| / max |Õ| to the energetic parts of the observed trace. Only frequencies in band = (f1, f2) [Hz] (default: all) and points with |S| > waterlevel · max |S| count. Like a travel time, but per time and frequency; meant for phase differences below π (a good starting model or Filtered data). width ≈ the dominant period. weights and window as for EnvelopeMisfit.

SeismicWavePC.ModelParameters — Type
ModelParameters(model::CartData, fields::Symbol...; mask=nothing, log=false, smooth=nothing, basis=nothing)

Parametrization of model by a vector θ: the listed fields (:vp, :vs, :rho, :Qp, :Qs, and for VTI models :epsilon, :delta, :gamma) vary, everything else stays as in model.

  • Without basis: one parameter per cell where mask is true (default: solid rock, vs > 0), the field value or, with log = true, its logarithm (keeps it positive, often better scaled for optimization and sampling).
  • smooth = L [km] (or (Lx, Ly, Lz)): the model is the initial one plus a smoothed perturbation, field = field₀ + S (θ - θ₀) in the mask (with log: its logarithm), with S a Gaussian smoothing exp(-(d/L)²) along each axis. The gradient is that of the smoothed model (Sᵀ g, exact), which removes the small-scale noise of cell-wise gradients near the sources and stations: the usual preconditioning of waveform inversions. θ stays one value per cell.
  • With basis, a vector of arrays of the size of the model: per field, one parameter per basis function, and field = field₀ + Σₖ θₖ basis[k] (layers, blobs, splines, …: few parameters, e.g. for Hamiltonian Monte Carlo).

The parameters of the fields follow each other in θ. initial_parameters(p) returns θ of model, to_model(p, θ) the model of θ.

SeismicWavePC.WaveformProblem — Type
WaveformProblem(params::ModelParameters, observed; sources, misfit=L2Misfit(), prior=nothing, kwargs...)

Waveform inversion problem: the objective (negative log posterior)

Φ(θ) = J(θ) - log prior(θ)

with the misfit J between the seismograms of to_model(params, θ) and observed (a Seismograms, or a vector of them for several shots with a vector of sources), as in misfit_gradient (misfit, and the simulate keywords dt, nt, stf, backend, nproc, … as kwargs).

prior is nothing (flat) or a function θ -> (log p, ∇ log p). For a Gaussian likelihood with noise σ use misfit = L2Misfit(weights = 1 / σ^2).

Use it with

  • objective(prob, θ), objective_and_gradient(prob, θ);
  • Optim.jl: optimize(Optim.only_fg!(fg!(prob)), θ₀, LBFGS());
  • LogDensityProblems.jl (with using LogDensityProblems, loaded by the samplers): log density -Φ and its gradient, for AdvancedHMC.jl (HMC, NUTS), DynamicHMC.jl, Pathfinder.jl, and Turing.jl (externalsampler);
  • ChainRulesCore.jl: a reverse rule for objective(prob, θ) (Zygote and other AD tools).

Models outside the valid range (negative velocities, density or Q, or an unstable time step) have Φ = Inf (log density -Inf), which samplers reject and line searches avoid.

SeismicWavePC.tf_misfits — Function
EM, PM = tf_misfits(syn, ref, t; band, nf=64, w0=6.0)

Single-valued time-frequency envelope and phase misfits (Kristeková, Kristek, Moczo & Day, 2006) of the seismogram syn against the reference ref (vectors, or arrays [it, …] for one value per trace) at the times t [s]:

EM = √(Σ ΔE² / Σ |W_ref|²),  PM = √(Σ ΔP² / Σ |W_ref|²),  ΔE = |W_syn| - |W_ref|,  ΔP = |W_ref| Δφ / π,

summed over time and nf log-spaced frequencies in band = (f1, f2) [Hz], with the continuous wavelet transforms W (Morlet wavelet, w0 = 6) and their phase difference Δφ. EM measures amplitude, PM phase (timing) errors, both relative (0.01 = 1 %); the usual criteria to compare seismograms of different codes. Multiply by 100 for percent.
